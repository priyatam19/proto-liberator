## Configuration

**Environment:**
- Set via command-line arguments to Python scripts (no .env files detected)
- libErator inputs passed as JSON file paths:
  - `--conditions`: conditions.json (function metadata)
  - `--apis`: apis_clang.json (function signatures, JSONL format)
  - `--driver`: driver.meta (for v1 mode; API sequences from libErator)

**Build:**
- Configuration parameters in `src/run_all.py`:
  - `--schema-mode`: v1 (fixed sequence) or v2 (dynamic dispatch)
  - `--mutation-mode`: nanopb (wire-only) or lpm (libprotobuf-mutator)
  - `--max-actions`: Max action entries (v2 mode)
  - `--max-calls-per-api`: Max params per API (v1 mode)
  - `--clang`: Path to clang compiler
  - `--cc-arg`: Extra compiler flags (repeatable)

- Fuzzing runtime via `scripts/run_campaign.sh`:
  - `--duration-sec`: Fuzzing duration (default: 86400)
  - `--max-len`: Maximum input length
  - `--timeout-sec`: Per-input timeout
  - `--jobs`, `--workers`, `--fork`: libFuzzer parallelization flags
