## Analysis: Why 0.69% Coverage?

libaom (AV1 codec) has fundamentally different characteristics from simpler libraries:

### 1. Complex Initialization Requirements

AV1 codecs require multi-step initialization:
1. Allocate codec context
2. Configure codec parameters (resolution, bitrate, etc.)
3. Initialize codec with valid configuration
4. Only then can encode/decode functions be called

Without valid initialization, most functions immediately return errors or crash.

### 2. Structured Input Requirements

Many functions expect:
- Valid video frame buffers (specific dimensions, formats)
- Properly formatted bitstreams
- Pre-allocated output buffers of correct size

Random bytes won't satisfy these constraints.

### 3. State Machine Dependencies

libaom operates as a state machine:
- Encoder: init -> set_config -> encode_frame (repeat) -> destroy
- Decoder: init -> decode_frame (repeat) -> get_frame -> destroy

Calling functions out of order causes failures.
