### By Target

#### cJSON
**Zero gaps** - All 78 functions have constraints. This makes cJSON the ideal reference target for tooling validation.

#### libpcap
**11 functions without constraints:**

| Category | Functions |
|----------|-----------|
| option_api | `pcap_alloc_option`, `pcap_free_option`, `pcap_get_option_int`, `pcap_get_option_string`, `pcap_set_option_int`, `pcap_set_option_string` |
| remote_api | `pcap_remoteact_accept`, `pcap_remoteact_accept_ex`, `pcap_remoteact_cleanup`, `pcap_remoteact_close`, `pcap_remoteact_list` |

**Blocking factors:**
- Callback functions (`pcap_loop`, `pcap_dispatch`) require function pointer parameters
- Resource dependencies (most APIs need valid `pcap_t*` handles)
- External resources (live capture needs interfaces, offline needs pcap files)

#### libaom
**196 functions without constraints:**

All 196 missing functions follow the pattern `aom_codec_control_typechecked_*`. These are generated by C preprocessor macros that expand codec control IDs into type-safe wrapper functions. libErator's static analysis does not track macro expansion.

**Blocking factors:**
- Macro-generated functions not captured by libErator
- Complex codec initialization sequences required
- State machine dependencies (encoder/decoder must be initialized)
- Structured input requirements (valid video frames/bitstreams)

## Key Findings

### 1. cJSON (Best Performer)
- **Constraint coverage:** 100% (78/78)
- **Function coverage:** 76.99%
- **Assessment:** Highest coverage due to simple API design. All functions have usable constraints. Good candidate for 100% coverage target.
- **Recommended action:** Optimize v2 super-harness, add schema completeness check

### 2. libpcap (Middle Tier)
- **Constraint coverage:** 88.9% (88/99)
- **Function coverage:** 13.12%
- **Assessment:** Good constraint coverage but low function coverage. Blocked primarily by callback-heavy APIs and resource dependencies. 11 missing functions are newer/platform-specific APIs.
- **Recommended action:** Focus on `pcap_open_dead` path (no external resources), generate pcap file corpus

### 3. libaom (Hardest)
- **Constraint coverage:** 19.3% (47/243)
- **Function coverage:** 0.69%
- **Assessment:** Fundamental constraint gap from macro-generated functions. Codec state machine requires complex init sequences. Most functions need valid video data.
- **Recommended action:** Focus on stateless functions (version info, error strings). Realistic target is 10-20% without manual constraint generation.

## Recommendations for Phase 2
